keys, OpenAlex locations, the authorized Google Books search endpoint, and the
authors' Lume/UFRGS discovery routes. Publisher content exposed an abstract and
50 references but no complete public inclusion table/supplement. OpenAlex listed
no OA repository copy. Author-repository discovery led to a security challenge;
no challenge or access control was bypassed.

Observed table citations were mapped to Crossref keys `10_CR25` and
`10_CR28`–`10_CR39` **only after** table membership was observed. No missing member
was inferred from the bibliography. The count alone does not prove thirteen
papers are incomplete for fourteen studies, but the snippets did not establish
the complete paper-level universe either. The abstract's eleven pure and six
modified/doped groups are not seventeen independent papers.

No AP gold array or post-cap dropped-gold list is asserted. For example, ref34
has July 2021 print metadata, but an earlier online date would have to be checked
before deciding whether it falls after 2021-04-01. A later print date cannot by
itself justify dropping a paper. Because the complete source list remains
unverified, the entire AP lead is withheld rather than masking unknown members
as date exclusions.

## Method and provenance

The installed discovery CLI was `rforge v0.1.21` (revision `a9f939c`). Four
curator queries were run through `rforge search batch --continue-on-error --stats`
against Crossref (limit 20 each) and OpenAlex (limit 50 each):

- `systematic review artificial photosynthesis`
- `systematic review photocatalytic hydrogen`
- `systematic review photocatalytic carbon dioxide reduction`
- `systematic review solar water splitting`

Saved batch coverage: Crossref **80 raw / 80 deduped** records, OpenAlex
**200 raw / 198 deduped**, zero connector failures in either batch. These counts
are within-batch only, not a cross-provider unique-paper count or a recall score.
The manifest, result files and source statistics are scratch curator artifacts;
none is a benchmark snapshot or a retrieval plan. Follow-up title/PRISMA queries
used public OpenAlex, Crossref and DataCite APIs to identify alternative reviews
and public locations. Publisher pages and the authorized book preview above
were inspected for qualification, not used to generate benchmark answers.

Search Hub's DuckDuckGo searches mostly returned no parseable results; no Brave
key was configured. Elsevier's unauthenticated article API returned only core
metadata for Hossen DOI 10.1016/j.rineng.2022.100795 and refused full view without
a key. Those access failures do not demonstrate that qualifying reviews do not
exist, and are not an owner-only blocker. No access control was bypassed.

Only source identities, locators, factual counts, date precision and qualification
notes are committed. No PDFs, article text, abstracts, API bodies or book-preview
images/snippet payloads are redistributed. The owner decision authorizes the
recorded no-AP fallback; it does not authorize inventing members, treating
bibliographies as inclusion lists, changing other composition requirements,
approving the set, or recording snapshots.
