# Pi agent-tier pilot — 2026-10-21

Status: **48 observations recorded; blinded scores frozen and report complete.**
Offline scoring/publication finished on 2026-10-22 from the retained original
observations; no paid agent was rerun for this retry.

**This is an outage-conditioned pilot, not evidence of superiority over functioning
native search.** All 24 without-tools observations encountered DuckDuckGo HTTP 202
responses with no parseable results and returned empty bibliographies. All 24
with-tools observations also lost at least one provider; 23 exceeded the token cap
on an indivisible response. These failures and partial answers remain in the matrix.
The positive recall contrast is descriptive of this execution, not a release gate.

### Scoring repair and blinding

The first attempt's scoring failure was **schema**, not a request to retry bad
outcomes: submitted scheme labels were `DOI`, `PMID`, `PMCID`, `CrossrefID`, and
one bibliography rank contained empty-string PMID/PMCID placeholders. The strict
scorer rejects both unsupported scheme spelling and empty identifier values.
Before any successful scoring/condition join, the deterministic
[extractor](../../benchmarks/agent-tier/live/extraction.py) case-folded **2,075**
nonempty scheme labels (including DOI-shaped Crossref connector alias
`CrossrefID` → `doi`) and omitted
**two empty identity placeholders**, retaining their bibliography rank. Every
nonempty identifier value, rank, duplicate, claim and quote is unchanged; no
identifier was inferred, no paper removed and no relevance label modified.
The original failed bundles and raw observations remain privately retained.

The projected answers were blinded afresh, checked for attribution, then scored
in bubblewrap with a separate filesystem/PID/network namespace containing only
the statically built utility, locked set, blind answers and fresh score-output
mount. The scorer received no checkout, registration, transcript, counters or
mapping. Only after the freeze receipt existed did the custodian join conditions
and usage. This is automated identity scoring, not independent human relevance
adjudication or independent verification of scientific claims.

## Effect size and expanded-run planning

The registered calculation uses question-level sample SD **0.2765895382** and
paired standardized effect d_z **1.0322728576**. For a prospective absolute recall
difference **0.05**, two-sided alpha **0.05**, power **0.8**:

```text
Q_raw = ((Phi^-1(0.975) + Phi^-1(0.8)) × 0.2765895382 / 0.05)^2
      = 240.1812853
Q = max(24, ceil(Q_raw)) = 241 independent review families
N=3 gives 241 × 2 × 3 = 1,446 observations
```

This meets the registered sizing calculation, **not approval to spend or expand**.
Q=8 gives an unstable SD; the normal approximation ignores finite-sample t/power
adjustments, and this variance is conditioned on native outage and extensive
with-tools budget stops. Do not extrapolate its positive mean or spend to healthy
services. An expanded experiment requires functioning qualified native search,
a separately approved independent set, new registration and spending authority.
Do not tune on these held-out outcomes and reuse this set for fresh claims.

Other limitations: independent-family assumptions, small/domain-uneven Q,
retrospective live indexing rather than historical reconstruction, service/model
drift and provider prompt caches. Native date enrichment excludes unknown/late
publication metadata and can reduce coverage. No raw native cluster membership
or pinned citation-facet corpus is wired here, so dedupe/citation metrics remain
unavailable. There is no artificial-photosynthesis held-out question under the
set's approved waiver. This pilot is not comparable to the
[engine replay baseline](baseline-2026-10-19.md) as an implementation delta:
inputs, execution mode and unit of comparison differ.

## Offline readback and reproduction

See [adapter instructions](../../benchmarks/agent-tier/live/README.md) for live
prerequisites and the identity-preserving extraction step. No live access is
needed to rescore the committed blinded bundle:

```sh
work=$(mktemp -d "$TMPDIR/pi-pilot-readback.XXXXXX")
CGO_ENABLED=0 go build -o "$work/agent-tier" ./benchmarks/agent-tier
pkg="$PWD/benchmarks/agent-tier/pilot-pi-2026-10-21"
mkdir "$work/blind" "$work/scores"
cp "$pkg/answers.json" "$work/blind/answers.json"
bwrap --die-with-parent --new-session --unshare-all --clearenv \
  --ro-bind "$work/agent-tier" /agent-tier \
  --ro-bind "$PWD/benchmarks/sets/pool-a" /set \
  --ro-bind "$work/blind" /blind --bind "$work/scores" /out \
  --proc /proc --dev /dev \
  /agent-tier score --set /set --blind /blind --out /out/scores.json
cmp "$pkg/scores.json" "$work/scores/scores.json"
cmp "$pkg/scores.json.freeze.json" "$work/scores/scores.json.freeze.json"
```

Both comparisons must match byte-for-byte. Rejoining the original audit requires
the custodian's private projected experiment and mapping, not disclosure of them
to the scorer. All original digests and the extraction receipt are retained for
that audit. The public report supports recomputation of question-level contrasts,
t intervals and the sizing formula without private billing identities.
