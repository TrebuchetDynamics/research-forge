ResearchForge ships an agent skill pack. Agents can install it from GitHub, use `rforge`, run literature searches, record provenance, expand citations, screen/extract evidence, and build auditable review artifacts.

## Ask your agent

```text
Read https://github.com/TrebuchetDynamics/research-forge/blob/main/docs/agent-install.md,
install ResearchForge for this host, then use the research-forge skill to research: <your topic>
```

The [canonical agent installation guide](https://github.com/TrebuchetDynamics/research-forge/blob/main/docs/agent-install.md) covers Claude Code, Codex, Pi, Hermes, and the generic skill fallback for other hosts such as OpenCode.

## Install for your host

Follow that guide for native integration, prerequisites, verification, updates, and removal. The unified installer defaults to `--for all`: the CLI engine, public skills, and native integrations for the current user. Use `--for cli` for only the engine or `--for skills` for the public skills and native integrations for installed Claude Code, Codex, Pi, and Hermes hosts, without the engine. Use `--only skills` for standalone public skills only. Do not keep a standalone skill copy alongside a native plugin in the same host.

## What the pack includes

The public pack contains six skills:

| Skill | Purpose |
| --- | --- |
| `research-forge` | Research methodology, provenance, verification, and human approval gates. |
| `lit` | Literature synthesis from a research directory. |
| `paper` | Resolve a paper by identifier or title. |
| `brief` | Write a brief from a completed search directory. |
| `compare` | Compare two completed search directories. |
| `replicate` | Draft a replication plan, not execute experiments. |

Claude Code, Codex, and Pi expose the methodology skill plus five explicitly invoked workflows. Hermes currently exposes only `research-forge`; see the installation guide for its separate MCP setup.

The repository's [developer skill inventory](https://github.com/TrebuchetDynamics/research-forge/blob/main/SKILLS.md) also lists `research-forge-*-tdd` skills for building and maintaining ResearchForge. Those developer skills are not part of the installed public research pack.

## Use it

```text
Use the research-forge skill to research: <your topic>
```

Good agent runs still require source terms review, owner approvals for scientific claims, and explicit redaction before sharing packages.
