## Discovery evidence and readiness

- Baseline: internal/webui/webui.go:67 renders `<form hx-get="/search/results" hx-target="#search-results" hx-indicator="#search-loading">`, but internal/webui/server.go:102 registers only `mux.Handle("/search", NewSearchHandler(ui.NewSearchFormState(defaultSearchSources())))`. An isolated httptest probe of the real NewRouter returned `GET /search/results status=404 body="404 page not found\n"`. NewSearchHandler ignores the request and executes a fixed view model, so `.Query` is always empty despite the field existing, and the source loop hardcodes every checkbox `checked`. docs/todo-completion-audit.md records the web GUI search screen as Complete, so the dead target contradicts the recorded completion claim.

Actual searching still runs through the CLI (rforge search), which keeps provider and live boundaries intact.
